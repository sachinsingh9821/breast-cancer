# breast-cancer

Multi-view mammography screening system: 4-view exam → per-breast malignancy probability,
localization and calibrated uncertainty.

> **Not for clinical use.** Portfolio / research project only.

## Quickstart

```bash
py -3.11 -m venv .venv
# Linux/macOS: make setup   |   Windows: .\tasks.ps1 setup
```
